# 中学理科実験用オシロスコープ (School Oscilloscope)

中学生が理科の「音の性質（音の大きさ・高さ・音色）」の単元で活用できる、軽量・完全無料・直感操作のWebオシロスコープアプリケーションです。  
ログイン不要で、GIGAスクール端末（Chromebook、iPad、Windowsタブレット等）のブラウザからURLを開くだけですぐに実験が始められます。

## 👨‍🏫 先生向けクイックスタート（授業での配り方）

Google Classroom、ロイロノート、Teams、または紙のプリントで**「クリックするだけで先生の設定通りに起動するリンク」**を簡単に配布できます。生徒にパスコードを入力させたり、カメラでQRコードを読み取らせる手間は一切ありません。

### 使い方（わずか3ステップ）
1. 画面右上の **「⚙️ 先生用設定」** をタップ（パスコード不要で直接開きます）。
2. 「🔔 おんさの実験」「🗣️ 声の観察」「🎸 弦・モノコード」などからおすすめセットを選ぶか、ゲイン・横マス数・目盛りを自由に調整。
3. 最上部の **「📋 この設定の生徒用リンクをコピー」**（またはプリセット横の「🔗 リンクをコピー」）をタップ。
4. Google Classroom やロイロノートに貼り付けて生徒へ送信！

> 生徒はそのリンクを開くだけで、先生が指定した最適な波形倍率・目盛り・テーマで即座にオシロスコープが起動し、迷わず実験に直行できます。

## ✨ 主な機能と特徴

### 1. 3つの学習タブ
- 〰️ **波形観察・比較**:
  - **音A・音Bの個別キープ＆何度でも取り直し**: 2つの異なる音を画面上に残して比較。
  - **表示モード切替**: 「重ね合わせ（音A:青 / 音B:赤）」または「上下2段に並べる」をワンタップで切り替え。
  - **手動位相シフト**: 波の山と山をピッタリ重ね合わせる微調整スライダー＆画面直接スワイプ操作。
  - **実験データの画像保存**: クラス・番号・氏名および実験条件（音の強さや弦の長さ等）の入力が必須となっており、ヘッダーに印字されたPNG画像をノートや提出用としてダウンロード。
- 🎚️ **音の高さしらべ（チューナー）**:
  - 高精度自己相関法によるリアルタイム周波数（Hz）推定。
  - 音名バッジ（ドレミ / CDEFGAB）と、直感的なチューニングメーター針表示。
- 🔔 **基準音を鳴らす（おんさ）**:
  - 440Hz等のワンタップ発音、100〜2000Hzの周波数連続調整、波形選択（サイン波・矩形波・ノコギリ波）。
  - **内部直結モード**: アプリ内で鳴らした音をマイクを通さず内部結線で直接波形観察タブへ送信（ハウリング完全防止）。

### 2. 生徒にやさしい配慮（UI/UX最適化）
- **まわりの音カット（ノイズゲート）**:
  - 操作バーに常時表示。各班の机の騒音環境に合わせて生徒自身が0〜30%の安全範囲で微調整可能。
  - 初期値は先生が設定した推奨値が自動的にセットされます。
- **シンプルな画面構成**:
  - 難しいTIME/DIVやVOLTS/DIVなどの目盛りは初期状態で隠されており、生徒は「マイクON」「停止」「画像保存」に集中できます。
  - 一時停止時は画面中央に邪魔な文字を出さず、ボタンが「▶️ 再開する（オレンジ発光）」に切り替わります。

### 3. 先生専用コントロールパネル
- **マイク感度・波形ゲイン（Gain）**: 小さなおんさの減衰音も画面いっぱいに拡大（×0.5〜×10）。
- **波の表示幅（横マス数）**: 10マス〜50マス（10マス刻み）。波の1〜2周期だけを大きく拡大して観察可能（音A・音B共通連動）。
- **10種類のカラーテーマ**: クラシック（黒×緑）、サイバーシアン、心電図（淡緑）、ノート方眼紙（白×青）、黒板（学校風）、CUD高コントラスト（色覚多様性配慮）など。

## 🔬 授業での実験展開例

| 実験テーマ | 推奨設定 | 観察・発見のねらい |
| :--- | :--- | :--- |
| **① おんさの音の大小・高低** | ゲイン: ×5.0 / 横: 20マス / 0.5ms | 弱く叩いた時と強く叩いた時で「振幅（波の高さ）」が変わり、高い音のおんさでは「波の幅が狭く（振動数が多く）」なることを視覚的に比較。 |
| **② モノコード（弦の振動）** | ゲイン: ×2.0 / 横: 20マス / 1.0ms | 弦を短くしたり強く張ったりした時の音の変化を記録し、波の周期数がどう変化するかを確かめる。 |
| **③ 声の観察・音色の違い** | ゲイン: ×1.0 / 横: 40マス / 2.0ms | 「あ」「い」「う」など同じ高さで声を出しても波の形（波形）が全く異なることを観察し、「音色」の概念を学ぶ。 |

## 🌐 GitHub Pages への公開方法（完全無料）

静的ファイルのみ（HTML/CSS/JS）で構成されているため、サーバー契約やデータベース設定は一切不要です。GitHub Pages を有効化するだけで、1分で世界中にHTTPS配信できます。

1. 本リポジトリを GitHub にプッシュします。
2. GitHubリポジトリの **[Settings]** タブを開きます。
3. 左メニューの **[Pages]** を選択します。
4. **[Build and deployment]** の Source を `Deploy from a branch` に設定。
5. Branch を `main`（または `master`）、フォルダを `/ (root)` に設定して **[Save]** をクリック。
6. 数十秒後に `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` という公開URLが発行されます。

> **※注意**: マイク入力（Web Audio API）はブラウザのセキュリティ仕様上、**HTTPS環境（またはlocalhost）が必須**です。GitHub Pagesは標準でHTTPSに対応しているため、そのまま安心して生徒に配布できます。
